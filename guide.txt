# دليل تشغيل تطبيق الأمير جيم

التطبيق مجاني بالكامل ومش مربوط بأي اشتراك. البيانات بتنحفظ على **Firebase** من Google، والتطبيق نفسه بيكون على **GitHub**، والاثنين ببلاش.

> بتحتاج كمبيوتر ونص ساعة تقريباً، مرة وحدة بس. بعدها كل الموظفين بيستعملوه من جوالاتهم.

## شو بتحتاج

- حساب Gmail (للـ Firebase)
- حساب GitHub (بتعمله بالخطوة 3)
- ملف التطبيق **alameer-gym.zip** وملف **مفاتيح-الإشعارات.txt** (وصلوك من Claude)

## الخطوة 1: Firebase (البيانات والحسابات)

1. افتح [console.firebase.google.com](https://console.firebase.google.com) وادخل بحساب Gmail تبعك.
2. اضغط **Create a project**، سمّيه `alameer-gym`، اطفي **Google Analytics**، واضغط **Create project**.
3. من القائمة: **Build ← Authentication ← Get started**، اختار **Email/Password**، فعّل أول خيار، واضغط **Save**.
4. بنفس الصفحة: **Settings ← Authorized domains ← Add domain** واكتب `اسمك.github.io` (اسمك على GitHub، بتعرفه بالخطوة 3، فبتقدر ترجعلها بعدين).
5. من القائمة: **Build ← Firestore Database ← Create database**، اختار الموقع `eur3 (europe-west)`، ثم **Start in production mode**، ثم **Create**.
6. بصفحة Firestore افتح تبويب **Rules**، امسح الموجود، والصق كل محتوى ملف `firestore.rules`، واضغط **Publish**.
7. اضغط ⚙️ جنب **Project Overview** ثم **Project settings**. تحت **Your apps** اضغط أيقونة الويب `</>`، اكتب اسم `Alameer Gym`، واضغط **Register app**. رح يطلعلك كود فيه `firebaseConfig`، خليه مفتوح للخطوة الجاية.
8. بنفس الصفحة افتح تبويب **Service accounts** واضغط **Generate new private key** ثم **Generate key**. بينزل ملف JSON على جهازك.

> ملف JSON هذا سري. لا ترفعه على GitHub ولا تبعته لحدا. بنستعمله بالخطوة 4 بس.

## الخطوة 2: حط بيانات Firebase بملف config.js

1. فك ضغط `alameer-gym.zip`.
2. افتح ملف `config.js` بالـ Notepad.
3. انسخ القيم من `firebaseConfig` اللي بالخطوة 1 وحطها مكان الفراغات، بهالشكل:

```
firebase: {
  apiKey: 'AIza...',
  authDomain: 'alameer-gym.firebaseapp.com',
  projectId: 'alameer-gym',
  storageBucket: 'alameer-gym.appspot.com',
  messagingSenderId: '1234567890',
  appId: '1:1234567890:web:abc123'
},
```

4. احفظ الملف.

## الخطوة 3: ارفع التطبيق على GitHub

1. افتح [github.com](https://github.com) واعمل حساب (**Sign up**).
2. اضغط **+** فوق ثم **New repository**. سمّيه `alameer-gym`، اختار **Public**، واضغط **Create repository**.
3. اضغط **uploading an existing file**، واسحب كل الملفات والمجلدات اللي جوا مجلد `alameer-gym` (مثل `index.html` و`app.js` ومجلد `icons` ومجلد `server`)، واضغط **Commit changes**.
4. مجلد `.github` مخفي وأحياناً ما بيترفع بالسحب، فاعمله بإيدك: **Add file ← Create new file**، واكتب بالاسم بالضبط `.github/workflows/notify.yml`، والصق محتوى نفس الملف من المجلد، واضغط **Commit changes**.
5. افتح **Settings ← Pages**. تحت **Branch** اختار `main` و `/ (root)` واضغط **Save**.
6. بعد دقيقة أو اثنتين بيصير رابط التطبيق: `https://اسمك.github.io/alameer-gym/`

## الخطوة 4: أسرار الإشعارات

1. بمشروع GitHub افتح **Settings ← Secrets and variables ← Actions ← New repository secret**.
2. أضف 3 أسرار، كل واحد لحاله، بنفس الأسماء بالضبط:

- `FIREBASE_SERVICE_ACCOUNT`: افتح ملف JSON من الخطوة 1 بالـ Notepad، انسخ كل اللي فيه، والصقه.
- `VAPID_PUBLIC_KEY`: من ملف `مفاتيح-الإشعارات.txt`.
- `VAPID_PRIVATE_KEY`: من نفس الملف.

3. افتح تبويب **Actions**. إذا سألك، اضغط **I understand my workflows, go ahead and enable them**.
4. اختار **notify** ثم **Run workflow**، اختار `test` واضغط **Run workflow**. بعد دقيقة لازم تطلع علامة ✅ خضرا.

## الخطوة 5: أول تشغيل

1. افتح رابط التطبيق. بتطلعلك شاشة **تجهيز التطبيق**: اكتب اسمك وإيميلك وكلمة سر، واضغط **ابدأ**. هيك صرت المالك.
2. **الإعدادات ← حسابات الموظفين**: اضغط على جهاد ونور ومحمود، واعمل لكل واحد حساب، وابعتله اسم المستخدم وكلمة السر.
3. **الإعدادات ← الأسعار والكباتن**: الأسعار والكباتن جاهزين، عدّل اللي بدك إياه.
4. على كل جهاز: ثبّت التطبيق (الفقرة الجاية)، وادخل، وفعّل الإشعارات من **الإعدادات ← إشعارات هالجهاز**.

## تثبيت التطبيق على الأجهزة

- **أندرويد**: افتح الرابط بـ Chrome، اضغط ⋮ فوق، واختار **تثبيت التطبيق**.
- **آيفون**: افتح الرابط بـ Safari، اضغط زر المشاركة، واختار **إضافة إلى الشاشة الرئيسية**. الإشعارات على الآيفون بتشتغل بس من الأيقونة على الشاشة الرئيسية (iOS 16.4 أو أحدث).
- **ويندوز**: افتح الرابط بـ Chrome أو Edge، واضغط أيقونة التثبيت بآخر شريط العنوان.

## الإشعارات كيف بتشتغل

- كل يوم بالوقت اللي بتحدده (الافتراضي 10 الصبح) بيوصل إشعار لكل جهاز مفعّل: مين اشتراكه بينتهي اليوم، مين قرب ينتهي، ومين انتهى من قريب.
- بتضغط عالإشعار، بتفتح شاشة **التذكيرات**، وجنب كل مشترك زر واتساب. الرسالة بتكون جاهزة باسمه وتاريخ الانتهاء، بتضغط إرسال وبترجع للتطبيق وبتأكد إنها انبعتت.
- رسائل واتساب للمشتركين ما بتنبعت أوتوماتيك، لأنه الإرسال الأوتوماتيكي بيحتاج خدمة واتساب مدفوعة. التطبيق بيجهّزها بكبسة وحدة.
- لما تسجّل أو تجدّد اشتراك، في خيار **ابعت تأكيد على واتساب** فيه تاريخ التسجيل وتاريخ الانتهاء. اطفيه وإنت عم تنقل من الدفتر الورقي.

## أدوات المطوّر (مخفية)

اضغط على رقم الإصدار تحت صفحة الإعدادات 3 مرات ورا بعض. فيها:

- اختبارات بتفحص الحسابات والتواريخ والإشعارات وربط Firebase.
- معاينة إشعار الصبح، وإشعار تجريبي على الجهاز، وطلب إشعار تجريبي من السيرفر.
- محاكاة التاريخ: خلّي التطبيق يتصرف كأنه اليوم تاريخ ثاني وشوف مين بيطلع بالتذكيرات.
- إضافة وحذف مشتركين تجريبيين.
- سجل الأخطاء مع زر نسخ، وزر تحديث التطبيق ومسح الكاش.

## كيف أحدّث التطبيق أو أضيف ميزة؟

1. احكي مع Claude وقله شو بدك يتغيّر، وارفعله الملف اللي بدك تعدّله (أو المجلد كامل مضغوط). إذا ربطت حساب GitHub بـ Claude، بيقدر يعدّل ويرفع التحديث لحاله.
2. ارفع الملفات المعدّلة لـ GitHub: افتح المشروع، **Add file ← Upload files**، اسحب الملفات، **Commit changes**. الملفات الجديدة بتنكتب فوق القديمة.
3. زيد رقم الإصدار بملف `config.js` (مثلاً من `2.0.0` لـ `2.0.1`).
4. خلال دقائق، كل جهاز بيطلعله **في تحديث جديد** وبيضغط **حدّث**.

> البيانات ما بتتأثر بالتحديثات. هي على Firebase، مش بالملفات.

## إذا صارت مشكلة

- **الإشعار ما وصل**: افتح GitHub ← **Actions**. إذا في ❌ حمرا، اضغط عليها واقرأ السطر الأحمر (غالباً اسم سر غلط). تأكد كمان إنه الإشعارات مفعّلة على الجهاز من الإعدادات، وعلى الآيفون إنه التطبيق مفتوح من الأيقونة.
- **الإشعار بيتأخر شوي**: طبيعي. GitHub بيشغّل المهمة كل ساعة وأحياناً بتتأخر ربع ساعة.
- **«حسابك ما عنده صلاحية»**: الموظف موقوف، أو قواعد Firestore مش ملصوقة صح (الخطوة 1، رقم 6).
- **أي خطأ ثاني**: أدوات المطوّر ← سجل الأخطاء ← **نسخ**، والصقه لـ Claude مع وصف شو صار.
- **بدك ترجع لنسخة قديمة**: GitHub ← الملف ← **History**، بتقدر ترجع أي ملف لنسخته القديمة.

## النسخ الاحتياطي

- البيانات محفوظة عند Google. لو ضاع جوال أو انكسر، ما بيروح إشي.
- كمان، من **الإعدادات ← تنزيل ملف Excel** بتنزّل كل المشتركين وسجل الاشتراكات والحضور. ومن **نسخة احتياطية كاملة** بتنزّل ملف بتقدر ترجّع منه كل البيانات. يفضّل مرة بالأسبوع.

## الحدود المجانية

- Firebase المجاني بيعطي 50,000 قراءة و20,000 كتابة باليوم. هاد بيكفي نادي فيه لحد 1500 مشترك تقريباً و4 أو 5 أجهزة شغّالين طول اليوم.
- GitHub مجاني للمشاريع العامة. الكود بيكون عام، بس بيانات المشتركين مش عامة: محمية بقواعد Firebase وما بيشوفها إلا الموظفين.
